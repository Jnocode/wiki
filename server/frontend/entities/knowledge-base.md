## 知識庫規則

- 格式: Markdown (`.md`)，使用 Obsidian WikiLinks `[[]]`
- 代碼不可放入規劃目錄，僅存於 `dev_projects/`
- 使用標籤系統分類（#技術、#學習、#專案 等）
- 結構化資料使用表格
